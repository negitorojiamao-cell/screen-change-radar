# Screen Change Radar

Windows向けの画面変化検知ツールです。一定間隔で画面をキャプチャし、前回の画像から一定以上の変化を検知すると通知し、必要に応じて変化前・変化後の画像を保存します。

## 主な機能

- 1～60秒間隔で画面をチェック
- 画素差のしきい値と画面変化率を調整
- 変化を検知したらログ表示と通知音
- 変化前・変化後のフル解像度画像を保存
- 監視中の画面プレビュー
- GitHub ActionsでWindows用EXEをビルド

## EXEの入手方法

1. GitHubリポジトリの **Actions** タブを開きます。
2. **Build Windows EXE** の実行が完了するまで待ちます。
3. 成功した実行を開き、ページ下部の **Artifacts** にある `ScreenChangeRadar-Windows` をダウンロードします。
4. ZIPを展開して `ScreenChangeRadar.exe` を実行します。

ビルドがまだ完了していない場合は、Actionsの実行状況を確認してください。Artifactsはビルド成功後に表示され、30日間保存されます。

## Pythonから実行する方法

Python 3.10以降をインストールして、このリポジトリのフォルダーで実行します。

```powershell
py -3 -m pip install -r requirements.txt
py -3 screen_change_radar.py
```

または、エクスプローラーで `起動.bat` をダブルクリックします。

## 使い方

1. **監視開始** を押すと、現在の画面が基準として取得されます。
2. 以後の画面で、設定した変化率しきい値以上の変化があると通知します。
3. 画像保存が有効なら、`Pictures\ScreenChangeRadar` に `*_before.png` と `*_after.png` が保存されます。
4. **監視停止** で終了します。

設定は監視開始時に読み込まれます。変更した設定を反映するには、監視を停止して再度開始してください。

## 注意事項

- 画面全体を比較します。通知や動画、アニメーションなどでも変化として検知されることがあります。
- 監視対象の画面にパスワードや個人情報が表示される可能性に注意してください。画像保存を無効にすることもできます。
- 複数モニターは画面キャプチャ環境によって取得結果が異なる場合があります。
- 画面キャプチャ中に保護されたコンテンツや一部のアプリは正しく取得できない場合があります。
